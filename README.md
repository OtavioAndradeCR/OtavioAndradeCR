# 👋 Olá, eu sou o Otavio Andrade

## 🚀 Sobre mim

Sou **Desenvolvedor Backend .NET Pleno**, com experiência no desenvolvimento e na evolução de sistemas corporativos utilizando **C# e .NET (Framework, .NET Core e .NET 8)**.

Atuo no desenvolvimento de **APIs REST, microsserviços e aplicações corporativas**, participando de decisões relacionadas à **Arquitetura de Software**, definição de padrões técnicos e organização estrutural das aplicações.

Tenho como foco a construção de soluções **escaláveis, seguras, manuteníveis e bem estruturadas**, aplicando princípios e práticas como **Domain-Driven Design (DDD), Clean Architecture, Clean Code, SOLID e Design Patterns**.

Também desenvolvo aplicações web utilizando **JavaScript, TypeScript e React**, integradas a APIs e serviços backend. Minha formação em Full Stack inclui projetos práticos com **Python, Django e Flask**, ampliando minha experiência com diferentes tecnologias de desenvolvimento web.

Atualmente curso **Pós-Graduação em Arquitetura de Sistemas .NET**, aprofundando conhecimentos em arquitetura de software, microsserviços, sistemas distribuídos e soluções corporativas no ecossistema Microsoft.
