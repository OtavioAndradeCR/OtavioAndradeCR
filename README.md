# 👋 Olá, eu sou o Otavio Andrade

## 🚀 Sobre mim

Sou **Desenvolvedor Backend .NET Pleno**, com experiência no desenvolvimento de sistemas corporativos utilizando **C# e .NET (Framework, .NET Core)**.

Atuo no desenvolvimento e evolução de **APIs REST, microsserviços e aplicações corporativas**, participando também de decisões relacionadas à **Arquitetura de Software**, definição de padrões técnicos, organização estrutural das aplicações e aplicação de boas práticas de engenharia de software.

Tenho como foco a construção de soluções **escaláveis, manuteníveis e bem estruturadas**, aplicando conceitos como **Domain-Driven Design (DDD), Clean Architecture, Clean Code, SOLID e Design Patterns**.

Também atuo no desenvolvimento **Full Stack**, utilizando **JavaScript, TypeScript e React** para construção de aplicações web integradas a APIs e serviços desenvolvidos em .NET.

Atualmente curso **Pós-Tech em Arquitetura de Sistemas .NET**, aprofundando conhecimentos em arquitetura de software, microsserviços, sistemas distribuídos e desenvolvimento de soluções corporativas no ecossistema Microsoft.
